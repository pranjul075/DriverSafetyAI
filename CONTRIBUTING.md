# Contributing to DriverSafetyAI

## Setup
1. Clone the repository
2. Create Python 3.11 virtual environment
3. Install dependencies: pip install -r requirements.txt

## Adding New Features
- Add new violation types in src/violation_manager.py
- Add new detection classes in config/config.py
- Update visualization in src/visualization.py

## Model Training
- Use train.py for retraining
- Fine-tune from existing best.pt for faster results
